## Metric definitions

- **Extraction accuracy**: correct fields / total fields (7 per doc). Identifiers exact; currency within $1; percent within 0.05 pt; a truly-absent field is correct only if reported missing.
- **Hallucination rate**: reported non-zero numbers appearing in no source document / reported numbers.
- **Reconciliation error rate**: documents whose reported contributions/distributions disagree with the ledger / documents checked.
- **Traceability**: reported numbers whose cited source exists and contains the value / reported numbers.
